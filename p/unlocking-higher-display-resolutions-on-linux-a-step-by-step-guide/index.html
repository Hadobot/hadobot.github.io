Unlocking Higher Display Resolutions on Linux: A Step-by-Step Guide

Sep 27, 2025
4 minute read

Have you ever tried to access your older laptop remotely on a newer device and felt constrained by the default display resolution? That was exactly my situation: I found myself stuck with a laptop capped at 1366x768, which made remote access on my newer device frustratingly cramped. External monitors could unlock Full HD, but I wanted that resolution on the laptop’s own screen — and that’s when I discovered xrandr.

During my search for a solution, I came across a post that introduced the xrandr tool — a powerful utility for managing display resolutions on Linux. After following the steps, I successfully configured my old laptop to support Full HD resolution on its built-in screen. In this article, I’ll guide you through the process in a detailed, technical, yet beginner-friendly manner. By the end, your Linux system will remember the new resolution every time you boot up.

Step 1: Check Your Current Display and Available Resolutions

Before we add a new resolution, it’s important to know the names of your connected displays and the resolutions currently available. Open a terminal and run:

1

xrandr
  • xrandr stands for X Resize, Rotate and Reflect — it’s a command-line interface to interact with the X server display settings.
  • The output will list all connected displays (e.g., Virtual1, HDMI-1, eDP-1) and their supported resolutions.

Note: If your system is running Wayland instead of Xorg, xrandr may not work as expected. Wayland handles display management differently, and we will cover that in a future tutorial.

Step 2: Generate a New Resolution Mode

We want a resolution of 1920x1080 at 60Hz. To calculate the correct modeline, use the cvt command:

1

cvt 1920 1080
  • cvt (Coordinate Video Timing) generates a VESA Coordinated Video Timing modeline for a specific resolution and refresh rate.
  • The output will look something like this:
1
2

# 1920x1080 59.96 Hz (CVT) hsync: 67.50 kHz; pclk: 173.00 MHz
Modeline "1920x1080_60.00"  173.00  1920 2048 2248 2576  1080 1083 1088 1120 -hsync +vsync

This string is the exact configuration we need to add to xrandr.

Step 3: Add the New Mode to xrandr

Now we take the modeline from cvt and introduce it to your display:

1

xrandr --newmode "1920x1080_60.00"  173.00  1920 2048 2248 2576  1080 1083 1088 1120 -hsync +vsync
  • --newmode defines a new display mode that xrandr can use.
  • The quoted string "1920x1080_60.00" is the name of the new mode.
  • The numbers following it are detailed timing parameters (pixel clock, horizontal/vertical timings, sync settings).

Next, attach this mode to your display (replace Virtual1 with the display name from Step 1 if different):

1

xrandr --addmode Virtual1 "1920x1080_60.00"
  • --addmode <display> <mode> links the new resolution to a specific output so it can be selected.
  • After this step, the new resolution will appear in your display settings.

Step 4: Apply the New Resolution

To immediately switch to the new resolution, run:

1

xrandr --output Virtual1 --mode "1920x1080_60.00"

This command sets the display to the newly created Full HD resolution.

Step 5: Make It Persistent Across Reboots

To ensure your Linux system remembers this resolution every time you log in, add the xrandr commands to your profile:

1

gedit ~/.profile

Then append:

1
2
3

xrandr --newmode "1920x1080_60.00"  173.00  1920 2048 2248 2576  1080 1083 1088 1120 -hsync +vsync
xrandr --addmode Virtual1 "1920x1080_60.00"
xrandr --output Virtual1 --mode "1920x1080_60.00"

Save and close the file. These commands will execute automatically each time you log in.

Possible errors:

  • If you see an error like xrandr: cannot find mode, double-check the modeline generated by cvt.
  • Ensure you are using Xorg; these commands won’t work under Wayland.
