Access Your Home Router from Anywhere Using Tailscale and a Raspberry Pi

Dec 02, 2025
5 minute read

Have you ever been away from home and needed to access your router’s admin panel — only to realize that it’s restricted to devices on your local Wi-Fi? That was exactly the issue I faced. I wanted my remote devices, connected over Tailscale, to behave as if they were physically inside my home network. More specifically, I wanted to type my router’s address (e.g., 192.168.1.1) from anywhere in the world and instantly load its admin page.

This is entirely possible using Tailscale Subnet Routing, and one of the best devices to bridge your home network to your tailnet is a Raspberry Pi. In this article, I’ll walk you through how to configure your Pi as a Tailscale subnet router, enabling your remote devices to access your home LAN seamlessly including your router’s web interface.

By the end of this guide, your Raspberry Pi will automatically forward traffic between Tailscale and your home network, unlocking true remote LAN access.

Step 1: Understand the Goal — Making Remote Devices Act Local

Tailscale normally creates a peer-to-peer mesh network, allowing devices to talk securely to each other. However, most home routers and LAN devices don’t run Tailscale, which means you can’t reach them directly.

This is where a subnet router comes in.

A subnet router:

  • Lives inside your home network
  • Runs Tailscale
  • Forwards traffic between Tailscale and your LAN
  • Allows remote devices to reach LAN-only IPs (printers, NAS, routers, IoT devices, etc.)

If your home network is 192.168.1.0/24, then any device in your tailnet will be able to reach addresses like:

  • 192.168.1.1 (your router)
  • 192.168.1.50 (NAS)
  • 192.168.1.101 (a PC)

This is exactly what we want.

Step 2: Prepare Your Raspberry Pi

Before configuring routing, make sure:

  • Your Pi is connected to your home LAN (Wi-Fi or preferably Ethernet).
  • Tailscale is installed and logged into your tailnet.
    If not, install it with:
1
2

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

Once it shows as “active” in your Tailscale admin console, you’re ready to continue.

Step 3: Enable IP Forwarding on the Raspberry Pi

Enabling IP forwarding is a crucial step in setting up your Raspberry Pi as a router. Without it, your Pi cannot route packets between your local area network (LAN) and Tailscale.

Run These Commands

To enable IP forwarding, execute the following commands in your terminal:

1
2
3

echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
echo 'net.ipv6.conf.all.forwarding = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
sudo sysctl -p /etc/sysctl.d/99-tailscale.conf

What Each Command Does

  1. Creates a sysctl config file specific to Tailscale: The first command enables IPv4 packet forwarding.

    • 'net.ipv4.ip_forward = 1' sets the option in the system configuration to allow forwarding of IPv4 packets.
    • The tee command reads the output of the echo command and writes it to the specified configuration file.
    • The -a option ensures that the new setting is appended to the file rather than overwriting any existing content.
    • This configuration is saved in /etc/sysctl.d/99-tailscale.conf, which is specifically for Tailscale.

  2. Enables IPv4 and IPv6 forwarding so your Pi can act as a router: The second command achieves the same goal for IPv6, allowing your Pi to handle both IPv4 and IPv6 traffic.

  3. Applies the settings immediately without needing a reboot: The final command, sudo sysctl -p /etc/sysctl.d/99-tailscale.conf, executes the following:

    • sysctl modifies kernel parameters at runtime.
    • The -p option tells sysctl to load and apply the settings from the specified configuration file immediately.
    • Using /etc/sysctl.d/99-tailscale.conf, it activates the changes without requiring a system restart.

Verify Your Settings

After running these commands, it’s important to check that the settings have been applied correctly. Use the following commands:

1
2

sysctl net.ipv4.ip_forward
sysctl net.ipv6.conf.all.forwarding

You should see the following output:

1
2

net.ipv4.ip_forward = 1
net.ipv6.conf.all.forwarding = 1

This confirms that IP forwarding is enabled for both IPv4 and IPv6, readying your Raspberry Pi to act as an effective router!

Step 4: Advertise Your Home LAN Subnet to Tailscale

Next, tell Tailscale which LAN subnet your Raspberry Pi should expose. Replace the subnet below with the actual one your router uses:

1

sudo tailscale up --advertise-routes=192.168.1.0/24

This makes your Pi announce the entire LAN to your tailnet.

Common home subnets include:

  • 192.168.0.0/24
  • 192.168.1.0/24
  • 10.0.0.0/24

If you’re unsure, run:

1

ip route

Your LAN subnet will be the one associated with wlan0 or eth0.

Step 5: Approve the Route in the Tailscale Admin Console

Visit:

https://login.tailscale.com/admin/machines

Select your Raspberry Pi → look for Advertised Routes → enable the route you just declared.

This step activates the subnet routing functionality. Without approval, the route stays inactive.

Step 6: Test Access to Your Home Router

From any device connected via Tailscale (phone, laptop, remote server):

  1. Disconnect it from your home Wi-Fi.
  2. Ensure it’s connected to Tailscale.
  3. Open your router’s IP address (e.g., 192.168.1.1).

If everything is set up correctly, the router’s login page should load instantly — even if you’re thousands of miles away.

This means your remote device is now treated as a full member of your home LAN.

Optional: Step 7 — Add Redundancy with Multiple Subnet Routers

One of the best features of Tailscale is that you can advertise the same subnet from multiple devices, providing automatic failover.

Simply repeat the same setup on:

  • A second Raspberry Pi
  • A NAS
  • A Linux server
  • A home PC

As long as more than one device advertises the route, Tailscale will switch between them automatically if one goes offline.

This provides seamless, uninterrupted access to your LAN.

Quick Reference

For convenience, here are all essential commands together:

1
2
3
4
5
6
7

# Enable IP forwarding
echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
echo 'net.ipv6.conf.all.forwarding = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
sudo sysctl -p /etc/sysctl.d/99-tailscale.conf

# Advertise your home LAN subnet
sudo tailscale up --advertise-routes=192.168.1.0/24

After running these, don’t forget to approve the route in your Tailscale admin console.

Congratulations! Your Raspberry Pi is now acting as a Tailscale subnet router, allowing your remote devices to access your home router and any LAN device as if you were physically plugged in at home.
